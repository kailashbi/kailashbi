### Backend Architecture

```text
                ┌─────────────────┐
                │     Client      │
                └────────┬────────┘
                         ↓
                ┌─────────────────┐
                │ HTTP / API Layer │
                └────────┬────────┘
                         ↓
                ┌─────────────────┐
                │    Middleware   │
                └────────┬────────┘
                         ↓
                ┌─────────────────┐
                │ Router / Handler│
                └────────┬────────┘
                         ↓
                ┌─────────────────┐
                │ Validation      │
                └────────┬────────┘
                         ↓
                ┌─────────────────┐
                │ Service Layer   │
                └────────┬────────┘
                         ↓
                ┌─────────────────┐
                │ Repository / ORM│
                └────────┬────────┘
                         ↓
             ┌───────────┴───────────┐
             ↓                       ↓
        ┌─────────┐             ┌─────────┐
        │Database │             │  Redis  │
        └─────────┘             └─────────┘
```
